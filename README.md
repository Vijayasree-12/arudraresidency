# Arudra Residency Website — Reference Style

This package keeps the existing Arudra Residency property details and booking/contact functionality while matching the supplied screen recording's visual direction:
- Cormorant Garamond-style editorial serif headings with Manrope sans-serif body text
- Dark navy/charcoal, warm cream and muted-gold palette
- Hero image slideshow using existing property imagery
- Scrolling text band, subtle scroll-reveal/pop animations and hover effects
- Four equal-sized room cards with a consistent 3:2 photo frame
- Amenities, gallery lightbox, guest-review link, enquiry form, map, contact and WhatsApp links
- Responsive desktop and mobile layouts

## Preview
Open `index.html` in a browser. Keep the `assets` folder next to it.

## Notes
- The enquiry form opens a prefilled WhatsApp message; it does not store data on a server.
- Guest reviews link to the property's listing rather than showing invented testimonials.
- Room prices and unverified service claims are not fabricated.
- Google Fonts and the embedded map require an internet connection.
